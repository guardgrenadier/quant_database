## 配额依据与等待间隔

- 用户在个人中心确认当前账号 **10,000 积分**；不是从本地 Token 推算，也没有伪称自动查询成功。
- 官方[积分频次表](https://tushare.pro/document/1?doc_id=290)列示该档常规数据每分钟 500 次；特色接口的单独频次不用于这七项日频。
- 七项正式 Adapter 现有 REQUEST_INTERVAL 从 **1.3 秒改为 0.13 秒**，串行启动上限约 **461.5 次/分钟**，低于 500 次，留约 7.7% 余量。响应及处理本身超过 0.13 秒时沿用原算法自然不额外等待。
- 仅调整 suspend_daily、stock_st、stock_daily、daily_basic、adj_factor、stk_limit、index_daily；现有 Client 有限重试与 Retry-After 边界不变。
- 运维子进程结束轮询从 2 秒缩为 0.2 秒，减少短命令尾部等待；它不参与供应商限频。

账号核实过程：数据 API user 查询实际返回 40101“请指定正确的接口名”；官方网站前端的积分入口为 GET /wctapi/user_center/score，需要网页登录会话，本环境返回 40201“未找到登录信息”。用户随后提供积分值作为实际账户依据。未要求或保存浏览器 Cookie、密码，Token 不输出。更换 Token 或积分权限变化后需重新核频，不自动猜测额度。
