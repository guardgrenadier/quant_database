## 1. 动机与目标

- 从银河快照取得累计成交笔数 `num_trades`，差分形成分钟成交笔数。用户反馈已与权威逐笔聚合数据核对其语义；该特征不等同于委托单数或参与者数。
- 利用快照累计值区分“确认无成交”和“数据不足以确定”，结合 Tushare `suspend_d` 解释停牌等交易限制。
- 不以提高逐分钟 OHLC 精度为切换目的；允许明确的快照采样口径。
- 用户明确目标不回溯到 2010 年，该年的停牌记录反例不作为切换障碍。新的准确回溯起点尚未冻结。

需要分开表达三个问题：成交事实是否为零、数据证据是否充分、当时处于何种交易阶段或限制。零成交不等于停牌，无快照不等于缺失，有快照也不自动证明完整。

## 2. 已完成的真实验证

### 零成交认证

2026-09-03 六股、1,422 个连续竞价分钟，逐笔参考有 255 个零成交分钟。用严格包围整个分钟的前后快照、累计量额笔数均不变的保守规则，确认其中 229 个，全部与参考一致，没有将有成交分钟误判为零。

另有 26 个实际零成交分钟未被规则确认；不能把“未确认”直接解释为缺失。该判断依赖累计值忠实反映源时间、无重置或修订等前提，不能当作不受行情延迟影响的逐笔完整性证明。

证据：[脚本](../../data/probes/snapshot-zero-minute-20261023/check.py)、[摘要](../../data/probes/snapshot-zero-minute-20261023/summary.json)。

## 3. 候选重建算法

按股票日排序，对相邻真实快照计算累计 volume、amount、num_trades 的差分，再按业务归属聚合。不能先按分钟分组后在组内差分，否则会丢失分钟首条增量；当天首条也不能无条件与零作差。

候选流程：

```text
核对原始快照
→ 连续差分并保留前后时刻
→ 处理交易阶段边界
→ 阶段内部右闭归桶
→ 聚合量额笔数及价格
→ 认证零成交与未知
→ 按确认的价格规则填充
→ 统一验收发布
```

非等间隔不妨碍累计差分。无需补齐每个 3 秒槽位，不按缺口长度均摊成交。相邻快照包围目标分钟且累计值不变，可以在约定前提下支持零成交；跨多个分钟的正增量则不能仅凭两个端点恢复全部真实时间归属。

排序后可用列式差分、分组及边界扫描，以实际快照数 N 和分钟数 M 计，处理量为 O(N+M)；需要排序时另有排序成本。未做全市场全天快照的生产性能与流量配额验证。

## 4. 价格语义：讨论结论与未决选择

### high / low

银河快照 high/low 为日内累计极值，不能直接 max(high)/min(low) 当成分钟极值。688110.SH / 11:00 的源 high/low 始终为 118.40/114.50，而权威分钟为 115.19/114.99。

仅取 last 也会丢失可用信息。建议以有效成交快照 last 为基础，补充该更新区间内新出现的日内 high/low：high 上升才纳入新高，low 下降才纳入新低。300780.SZ / 09:31 的 max(last)=19.90，新报告日内 high=19.91，与权威该分钟高价一致。这个方法不能恢复未突破旧日内极值的所有局部波动，跨阶段极值更新也需要先确定归属。

### open / close

候选是首条／末条有效成交快照的 last；当天首次成交的 open 有时可直接从源 open 获得。相邻分钟 close=open 不是成交 OHLC 的不变量：688110 权威 09:30 close=117.24，09:31 open=117.12，不应强制连接。

### 零成交价格

讨论由第一轮的“成交 OHLC 为 NULL”转向用户提出的价格延续模型，尚未最终确认。最新建议：已确认零成交分钟 O=H=L=C=延续价；当天已有成交时使用最近可靠成交价（含开盘竞价），当天尚无成交时使用有效的当日 pre_close。量、额、笔数均为 0。只填 C 或 O/C 是另一种空值约定，不符合完整的“期间价格保持不变”表达。

须明确无成交期间四价是延续价格，不表示发生过成交。未知分钟不能套用零成交填价，也不能从未来首笔价格倒填。pre_close 是当日行情参考口径，不总等于昨天实际 close，需考虑除权息和上市首日。

实际样本 688057.SH 无开盘竞价成交，首次成交前 last/open/high/low 均为 0、pre_close=18.41；09:30:19 首次出现成交时 open=18.59、last=18.60。本次没有直到 10 点多才首次成交的样本。

## 6. 未决问题与重新启用条件

- 修订 Schema：增加 num_trades；允许确认零成交；决定四价空值／延续价、状态表达及时间语义。旧 DDL 的 volume/amount > 0、OHLC NOT NULL 等不能未经调整直接沿用。
- 决定快照是否成为独立 Canonical Dataset，以及分钟重建与跨源停牌解释放在哪里；当前仅有研究代码，没有新增正式抽象。
- 决定证据不足时是否阻断整个股票日、合法零行和全天停牌 Scope、依赖版本与算法变更后的重算规则；保留单股单日 Unit、统一验收和原子发布的核心职责。
- 验证银河的无变化快照压缩、交付终止与缺失信号；日总量守恒不能单独证明每分钟完整。
- 补充多日期、盘中／全天停牌、复牌、上市首日、除权息、长期无首笔成交、收盘竞价零成交、修订与丢包、盘后交易和适用历史时段的样本。
- 验证快照历史深度、全市场获取耗时、内存／存储规模及不可观测的周流量配额；竞价窄窗和分钟接口的性能结论不能直接外推到全天快照。
