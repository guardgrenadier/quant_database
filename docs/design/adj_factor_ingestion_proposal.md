## 1. 官方声明与关键语义

2026-10-30 核对官方文档：该因子由 Tushare 自行生产，支持单只股票历史和单日全部股票；输出 ts_code、trade_date、adj_factor，标注盘前 9:15–9:20 入库。该时间是供应商更新说明，不是本项目对当日终态的承诺。当前官方接口页没有列出单次行数上限或分页参数；6,000 行截断及 limit/offset 行为在本轮单独实测，不写成官方文档保证。

必须区分三个对象：

1. **原始因子 A(t)**：adj_factor 接口报告的证券日期值，本 Dataset 原样保存，不以抓取当日或请求 end_date 归一化。
2. **复权行情**：官方 A 股说明使用未复权价格与因子动态计算。后复权采用 `P(t) × A(t)`；以前复权基准 b 表达时为 `P(t) × A(t) / A(b)`。官方 pro_bar 按用户 end_date 确定复权基准；本轮没有调用 pro_bar 或新增该 SDK。
3. **供应商历史修订**：同一代码日期在不同抓取时刻可能被纠正，项目需允许重抓修订；这与前复权基准变化是两件事。

如果未来事件改变 A(b)，采用该新基准的历史前复权价格会变化，**即使旧日期 A(t) 没有被改写**。因此旧研究“除权后历史因子会被改写（前复权口径下旧因子整体变化）”不能作为原始 adj_factor 的普遍事实或冻结契约；它混淆了原始因子和归一化后的前复权结果。本方案以官方公式及本轮直接样本澄清，不修改旧研究的历史记录，也不宣称原始因子永远不修订。

## 3. 已确认的业务契约

| 方面 | 当前契约 |
|---|---|
| Dataset / 表 | `adj_factor` / `canonical.adj_factor`；旧研究中的 adj_factor_daily 是未落地建议，不涉及迁移 |
| 一行代表什么 | 供应商本次报告的一个证券、一个业务日期的原始复权因子；不等于除权事件、前复权因子或历史首次可得版本 |
| Schema | ts_code VARCHAR/pl.String；trade_date DATE/pl.Date；adj_factor DOUBLE/pl.Float64。三列均必填，因子无量纲、有限且 >0，保留源精度，不归一化、换汇或人为舍入 |
| Record Key | `(ts_code, trade_date)`；同键重复或冲突都阻断所属日，不去重 |
| 输入 | 显式 start_date/end_date，ASCII YYYYMMDD 闭区间；拒绝未来日期，允许上海当日但不保证盘前更新已完成或当日终态 |
| 范围 | 每个目标开市日供应商报告的全市场股票集合，含其报告的停牌证券；不按当前 stock_basic、daily 或 suspend_daily 筛历史 |
| 子集政策 | 首版不接受代码、交易所或上市状态子集；供应商支持单股历史不代表项目可用单股子集替换整日集合 |
| 上游 | 仅同库整个目标自然日区间的 `trade_calendar / SSE:YYYY-MM-DD` 成功版本；不自动运行上游 |
| Scope | 同一读取快照固定日历并区分开市 IN_SCOPE、休市 OUT_OF_SCOPE、成功 Coverage 下缺日历事实的 UNKNOWN；排除日所用版本同样保存并在发布前复核 |
| Publication Unit | 一个交易日的供应商全市场因子集合，Unit key 为 YYYY-MM-DD；请求页不拆发布 Unit |
| 替换 | 按日完整替换，重跑产生新成功版本且不累加；合格日期按现有一次发布事务提交，失败日期保留旧事实、Coverage 与成功指针 |
| 整日零行 | 开市日全市场零行 ERROR，不清除旧集合、不生成成功空版本；休市不请求、不生成本 Dataset 的 Coverage |
| 个股无行 | 只表示本次未报告；不得解释为因子=1、不适用复权或当天停牌，不补行、不前向填充、不借其他日期推值 |
| 历史覆盖 | 接受显式历史区间，不把本次最早抽样日作为供应商起点；整日无可用交付时明确失败，不声称该日已有成功覆盖 |

因子初值不强制为 1，合法小于 1 的正值也不因本次样本最小值为 1 而被拒绝。不设置单调性、固定涨幅、相邻日因子相等、数量等于日线或当前股票数等硬门禁；正常重复因子不表示数据陈旧或请求未更新。

## 4. 获取、准备与统一验收

沿用 daily_basic/stk_limit 的专属逐日分页政策，复用现有 Client，不提前新增通用分页框架或共享控制模型：

1. 每个开市日调用 `adj_factor(trade_date=..., limit=3000, offset=0)`，显式三字段；逻辑请求起始间隔 1.3 秒，Client 沿用有限重试、超时和逐次留证。
2. 必须有明确布尔 has_more；短页且 false 才完成。满页即使 false 仍续取尾页，短页 true 按实际行数前移；不以 count、非空行数或默认 6,000 行反推完整。
3. 请求失败、缺标记、空页 true、超请求页上限、重复页或明显忽略 offset 时，整个请求日不能发布；已取得的证据/部分 Raw 保留，继续其他日。整页重复按字段名及无序内容识别，跨页部分重复业务键由 Dataset 验收。
4. 按返回字段名核对三列并构造明确 Raw Schema，保留可信请求日与 offset 标签。字符串和 NULL 严格解码；因子只接受 JSON int/float/NULL，拒绝 bool、数值字符串等隐式修复。可复用已有 `sources/tushare/daily.raw_frame`。
5. 缺字段/Raw 类型错误是准备诊断；合法 NULL 和转换错误分开。NULL 因子最终由必填业务规则阻断，非有限数由 Dataset 显式阻断，不能将非法值转为 NULL 后放行。已完成获取的 COMPLETE 不代表准备或验收成功。
6. prepare 集中去首尾空白、空串转 NULL，核对源日期必须匹配可信请求日再严格转 DATE；错日或无效日期归因到原请求日，不能污染另一合格日期。每条源记录形成 Candidate 或关联明确问题，不静默去重、丢行或补事实。
7. Candidate 只含 Canonical 三列。Validator 合并 Scope、交付证据、准备诊断和 Dataset 业务规则，显式给出许可 Unit；Publisher 不从 Candidate 行数推断目标。

**ERROR：** 缺依赖、请求/分页不完整、缺列、坏类型/日期、错日、空业务键、因子 NULL/非有限/<=0、重复业务键、开市日全市场零行。按可信请求信息定位影响日，无法定位才全局阻断。

**WARNING：** 首版不新增无依据的跳变、单调性或证券数量阈值告警；因子变化、因子重复、停牌日有行及日线差集本身都不构成质量失败。后续若有具体可执行的异常诊断需求，再单独讨论对应规则与证据。

## 5. 修订、增量与研究消费

首版采用 **显式目标日期替换**：请求哪些完整交易日，就只修订哪些日。允许对旧日期重抓并接受源因子纠正，失败保护旧版；不引入自动重抓窗口、全历史扫描或公司行为触发机制。该政策满足当前接口和 Unit 契约，但日常只追加新日期**不证明历史已与供应商当前全链完全同步**。

应分别理解：

- 新公司行为可能改变后续日期的原始因子，也可能使选用新基准的历史前复权价格变化；不能据此自动重写所有已发布旧因子。
- 供应商若纠正旧因子或整段重定标，局部重抓可能让库内不同日期来自不同修订时刻。本轮没有观察并界定此类变更范围，成功 Coverage 不证明整个历史序列来自同一供应商快照或统一修订版本。
- 确需更新一整段历史时，按本契约显式重跑相应日期的**全市场**集合；不能把单股请求拼成整日成功 Coverage。若未来需要高效单股全链修订或保存整条序列快照，先另行确认 Unit、接口及存储政策，不在本切片暗中改变边界。

Canonical 保存当前已发布原始因子；Publication 只保存成功变更范围，没有历史行镜像。不是 PIT 因子库，不能按 publication_id 还原过去因子，也不能以 trade_date 代表当时已知的供应商值。需要严格可复现的回测快照时，应另行保存所用事实，而非仅保存版本号。

后续 Serving 若计算复权行情，需要同时明确行情范围、因子 Coverage、证券身份和基准日期 b；核对行情记录及基准所需的因子已成功覆盖，缺因子须显式表达，不能默认 1 或自动填充。前复权结果还依赖 A(b)，基准变化与因子历史修订都可能影响结果。目前不新增复权 Serving、调整分钟网格或改写 stock_daily 的字段，成交量额也不在此 Dataset 做复权换算。

## 7. 用户确认与边界

用户已授权按方案落地：**原始三字段、因子必填有限正数、全市场按日分页/替换、仅依赖日历、停牌日不排除、整日零行阻断、不设单调性门禁、显式重抓所选日且不保证全历史同一修订版本。** 这些是用户接受的项目政策，不是由一次实测推断出的供应商全历史保证。

具体历史下载区间尚未指定；首版不做全历史下载、自动调度/重抓、跨 Dataset 失效传播、PIT/序列快照、前后复权 Serving 或股利再投资回测。精确历史覆盖起点、退市/更名代码全历史口径、盘前数据终态、未来真实修订及全链重定标行为尚未穷尽验证；遇到冲突应按 AGENTS.md 报告并讨论，不以代码重新定义语义。
