# 网盘北交所分钟：收盘标签延后、缺失与大宗混入（2026-10-22）

## 结论

**对已验证的 2024-04-17 样本，15:01 确实高度符合“本应对应 15:00 的收盘成交，被源文件晚标一分钟”。** 这不是普通 15:00 后连续交易的证据，也没有证据支持把全天分钟统一减一分钟。

该解释有全市场量价交叉验证：248 只北交所股票，分钟累计到 15:01 后，成交量全部与官方日线精确一致；15:01 的 close 全部与官方收盘价一致。但全历史同时存在正常标在 15:00、延到 15:02、收盘附近数据疑似缺失，以及 15:30 混入大宗交易等情况，不能统一改标签来解决。

本轮只做研究取证，没有修改原文件、正式数据库、架构、共享接口或验收 invariant。

## 1. 15:01 晚标的直接证据

`920000.BJ / 2024-04-17`：

| 观察 | 成交量（股） | 收盘／该 bar close |
| --- | ---: | ---: |
| 网盘累计至 15:00 | 691,768 | 7.99 |
| 网盘 15:01 单根 | 63,200 | 8.05 |
| 网盘累计至 15:01 | 754,968 | 8.05 |
| 官方日线 | 754,968 | 8.05 |

15:00 自身量额为零，15:01 补上的量恰好等于日线缺口，并将价格更新为官方收盘价。该日分钟总额约 5,978,984.149 元，官方日线 5,978,984 元，差约 0.149 元，符合网盘 float32 表示带来的小误差量级。

这不是单股巧合。同日全部 248 只北交所股票：

- 15:00 全零量；15:01 有 246 根正成交量，另外 2 根也为零量。
- **248 / 248** 的分钟股数累计至 15:01 与官方日线相同。
- **248 / 248** 的 15:01 close，按两位小数比较，与官方日线 close 相同。
- **165 / 248** 的 15:00 close 尚不同于官方收盘价，15:01 才更新到一致。
- 全部股票累计至 15:01 的成交额与官方日线之差，绝对值最大约 1.285 元；不把 float32 微小差异解释成业务差异。
- 246 根正量的 15:01 bar，均满足 `amount ≈ vol × 官方收盘价`，最大金额残差仅 0.25 元。这进一步支持它们对应单一收盘价格的成交，而非普通收盘后连续交易。

因此，这一天将 15:01 理解为收盘成交的延后标签，有很强的证据支持。但这仍是分钟与日线的交叉推断，不是逐笔成交时间对照；不能证明每根 15:01 的全部字段都是独立、纯净的集合竞价聚合。

特别是其中 165 根正量 bar 的 open 与 close 不同。`920000` 的 15:01 open 仍为约 7.99、close 才是 8.05，而量额全部对应 8.05 的成交。因此，“量额和 close 对应收盘成交”不等于“原 OHLC 就是纯集合竞价四价”，单改标签也没有消除这个价格口径问题。

证据：`daily_20240417.json`、`bj_daily_crosscheck_20240417.json`、`bj_920000_daily_comparison.json`，均位于 [本地证据目录](../../data/probes/minute-zero-volume-20261022/)。

## 2. 不是北交所全历史统一晚标一分钟

对全部源文件中的 **186,417 个北交所股票日**，仅按 15:00、15:01、15:02 三个槽位的量分布分类：

| 源记录表现 | 股票日数 |
| --- | ---: |
| 仅 15:00 有正量 | 67,264 |
| 仅 15:01 有正量 | 81,282 |
| 仅 15:02 有正量 | 554 |
| 三个槽位均无正量 | 37,317 |

没有发现同一股票日在这三个槽位中有两个或以上槽位同时正量。“仅某槽位有量”只描述这三个位置，不表示全天只有该槽位成交；“均无正量”也不直接等于缺失，可能有确实无成交的情况。

这种差异并非只按年份变化。同一只 `920000.BJ`：

| 日期 | 正量所在收盘槽位 | 与官方日线的关系 |
| --- | --- | --- |
| 2024-04-17 | 15:01，63,200 股 | 加入该根后总量、收盘价一致 |
| 2024-04-18 | 15:01，51,584 股 | 加入该根后总量、收盘价一致 |
| 2024-04-19 | 15:00，4,985 股 | 累计至 15:00 已一致，15:01 是零量占位 |

因此，不能按“2024 年北交所统一晚一分钟”这样的规则解释。

还有晚两分钟的例子。`920169.BJ / 2022-07-15`：15:00、15:01 量都为零，15:02 为 **10,000 股**；累计至 15:00 比官方日线恰好少这 10,000 股，加入 15:02 后股数精确一致，close 从约 6.15 更新为官方收盘价 **6.20**。同日 `920223.BJ` 的 15:02 为 57,398 股，也恰好补齐其日线量差。

该日匹配到官方日线的 102 只北交所股票，累计至 15:02 后股数全部一致；其中只有上述两只在 15:02 有量。说明同一天不同股票也可能采用不同的收盘标签。

证据：`bj_stock_days.parquet`、`bj_closing_annual.json`、`bj_closing_dates.json`、`daily_20220715.json`、`bj_daily_crosscheck_20220715.json`。

## 3. 有些情况是数据缺口，平移无效

**2026-04-13**，网盘中与官方日线匹配的 **306 只**北交所股票：

- 15:00 的量全为零，没有 15:01、15:02 源行。
- **306 / 306** 的分钟总成交量少于官方日线。
- **235 / 306** 的网盘 15:00 close 不同于官方收盘价。

例如 `920000.BJ`：网盘全日 **400,454 股、末价约 15.83**；官方日线 **409,442 股、收盘 15.93**。量少 **8,988 股**，对应金额缺口约 143,178.536 元，与约 15.93 元的收盘附近成交相符。

这组事实支持“源文件缺失了收盘附近成交”的判断，不能解释为简单把收盘 bar 藏到另一个标签；不过逐笔缺失位置仍未直接核对，不能宣称日内其他分钟绝无问题。

进一步核对这 306 只股票的量额缺口，全部近似满足 `缺失金额 = 缺失股数 × 官方收盘价`，最大残差约 1.567 元，进一步支持缺失的是收盘价成交这一判断。金额残差仍保留，不通过改写分钟值强制对齐。核查结果见 `bj_closing_price_amount_checks.json`。

另有独立的早盘缺口：全历史 **21 个交易日、4,924 个北交所股票日**，源记录直接从 **11:10 或 11:12** 开始。例如 `920000.BJ / 2024-04-16` 只有 171 行，从 11:10 到 15:30；分钟量比官方日线少 410,893 股。这不是正常 271 槽位模板，也不应通过补零掩盖。

证据：`daily_20260413.json`、`bj_daily_crosscheck_20260413.json`、`time_labels_bj_missing_edges.json`。

## 4. 15:30 的量是另一回事：样本已确认大宗交易

2024-04-17 有 5 只北交所股票的 15:30 非零量。逐只查询官方 `block_trade` 后，五只股票的成交量全部对应：

| 股票 | 网盘 15:30 股数 | 官方大宗交易股数 |
| --- | ---: | ---: |
| 920062.BJ | 100,000 | 100,000 |
| 920267.BJ | 100,000 | 100,000 |
| 920346.BJ | 108,888 | 108,888 |
| 920556.BJ | 200,000 | 200,000 |
| 920978.BJ | 198,000 | 198,000 |

这些股票累计至 15:01 的量已等于官方日线量；再加 15:30 后，超出的股数恰好是大宗交易股数。不能把 15:30 的量也挪到 15:00 当作收盘竞价。

同时，源 15:30 OHLC 不一定等于实际大宗成交价。例如 `920062.BJ` 的 15:30 四价都是 5.75，但量为 100,000 股、金额 385,000 元，恰好对应官方大宗成交价 **3.85**。这类行的量额和价格字段可能混用了不同口径，不能把它当作普通成交 K 线使用。

证据：`bj_block_trade_20240417.json`、`bj_1530_block_matches.json`；接口及量单位见 [Tushare 官方大宗交易文档](https://tushare.pro/wctapi/documents/161.md)。官方文档中量为万股，交叉核对时乘 10,000 转为股。

## 5. 可以确认到哪里

可以确认存在收盘量晚标至 15:01／15:02 的样本、日期与股票之间的非统一处理、缺口，以及大宗混入。不能据此将全部北交所分钟统一减一分钟，也不能把“没有收盘量”的行自动补成真实成交。

本轮新增官方日线 2022-07-15、2024-04-17、2026-04-13，均为成功、`has_more=false`、低于 6,000 行的完整单次响应；单位按[官方日线文档](https://tushare.pro/wctapi/documents/27.md)将手／千元转为股／元。另复用了此前 `920000.BJ` 全历史官方日线证据，得到 791 个重叠股票日的补充对照。

尝试直接取 `stk_auction_c / 2024-04-17`，官方返回 **40203：没有接口访问权限**，未取得独立集合竞价响应；未重复调用此前受限的 `stk_mins`。因此“晚标的正是收盘集合竞价成交”仍属于很强的交叉推断，供应商内部为何如此归桶，以及日内每根分钟的精确时间边界，尚未证明。

取证分析脚本：`data/probes/minute-zero-volume-20261022/bj_closing.py`。已有原始证据齐备时，可从仓库根执行 `uv run --frozen python data/probes/minute-zero-volume-20261022/bj_closing.py` 重做交叉统计与关键断言；它只读原始 Parquet 和已存官方响应，不发布或改写业务数据。
