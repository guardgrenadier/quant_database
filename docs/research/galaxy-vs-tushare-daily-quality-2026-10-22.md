# 银河 vs Tushare 日线（股票/指数）质量对照与接入建议

日期：2026-10-22（Asia/Shanghai）
状态：真实接口对照完成；本报告只提出接入建议，不冻结任何 Schema/Scope/Unit 契约，未修改正式 ingestion、Canonical 或架构。

## 1. 结论

**日线层面（股票日线 + 指数日线）Tushare 官方接口质量与适配性均明显优于银河，建议日线主链路接入 Tushare；银河保留给分钟线与集合竞价快照（Tushare 不具备的能力）。** 银河日线可选作 2013 年后的抽样交叉验收源。

依据要点：

1. **历史深度**：Tushare 股票/指数日线可回溯到上市/发布首日（上证指数 1990-12-19、平安银行 1991-04-03）；银河统一从 2013-01-04 开始，北交所当前代码仅从 2025-10-09（920 代码切换点）开始，且**完全不支持申万行业指数**。
2. **数值口径**：2013 年后重叠期两边逐日集合完全一致、成交量 100% 精确一致；但银河早期沪市收盘价是"最后一笔成交价"口径，与交易所官方收盘价（Tushare 口径）系统性相差分位级，直至 2018-08-20 上交所收盘集合竞价改革后消失；银河早期沪系指数点位与官方发布值存在可见偏差（最大约 0.3%）。
3. **工程适配**：Tushare 为 HTTPS JSON + has_more 分页，项目已有 5 个 Dataset 的成熟接入模式；银河为 C++ SDK + WSS 直连，无完整性标志、无超时、会话有挂起先例、周流量配额不可观测，正式接入需 worker 进程隔离（详见[银河接口探查报告](galaxy-amazingdata-interface-probe-2026-10-19.md)）。

## 2. 范围、样本与方法

样本：7 只股票（000001.SZ、600519.SH、002168.SZ、300819.SZ、300104.SZ（退市+停牌）、688981.SH、920000.BJ（北交所））+ 6 只指数（000001.SH、000300.SH、000905.SH、399001.SZ、399006.SZ、801010.SI（申万））。

方法：

- 银河：高层 `query_kline` 按代码全历史（19900101–20261021）范围查询日线；另对 3 个常规交易日（20240417、20260903、20261016）与 4 个语义用例（全天停牌、覆盖起点、覆盖前）做底层 `tgw.QueryKline` 单日原始整数抓取。
- Tushare：`daily` / `index_daily` / `sw_daily` 按代码 × 十年分片串行抓取（间隔 ≥1.3 秒，瞬时错误重试 ≤3 次），每片检查 has_more。
- 对照：覆盖集合（仅单侧日期）、OHLC 按 1e-6 元整数级比对、成交量按"手×100=股"假设、成交额按"千元×1000=元"假设。
- 仲裁：本地历史分钟文件（逐分钟第三方源）、搜狐历史行情（官方收盘价独立转载）、上交所 2018-08-20 收盘价规则改革边界。

探针脚本：`scripts/compare_daily_galaxy_tushare.py`（获取与对照）、`scripts/analyze_daily_compare.py`（分歧归因与仲裁）。两者均为可丢弃研究代码；只读两侧接口，不写正式数据库。

要点：

1. **2013 年以来沪深重叠区，两侧交易日集合完全一致**（6 个沪深股票/指数样本"仅单侧日期 ≥2013"均为 0），银河在其覆盖期内不缺日。
2. 银河所有股票/指数日线统一从 2013-01-04 开始，与官方手册"K 线起点 2013 年"一致；2012-12-31、2000-01-04 单日实测为 `kDataEmpty(-76)`。
3. 北交所 `920000.BJ` 银河仅从 2025-10-09（920 代码切换）起有数据，2024-04-17 单日实测 `kDataEmpty`；Tushare 在当前代码下已拼回 2017-03-29 起的全历史。银河若要北交所历史需用旧代码另行验证，本轮未测。
4. 银河不支持申万 `.SI` 代码（高层直接抛"未知类型"）；项目 `index_basic` 目标包含申万行业指数，其行情只能走 Tushare `sw_daily`（Tushare `index_daily` 实测不含申万，返回 0 行）。
5. 停牌语义一致：300104.SZ 全天停牌日（2017-04-17）两边均为空（银河 `kDataEmpty`，Tushare 0 行）；未来日/非交易日两边均为合法空。

## 4. 数值一致性（2013 年后重叠期）

### 4.1 股票

- **成交量：全部样本 100% 精确一致**（Tushare 手 ×100 = 银河股；底层整数级对照亦全中）。
- **价格（OHLC）**：深市样本近乎满分——002168.SZ、300819.SZ、688981.SH 全历史 0 分歧；000001.SZ 仅 2016 年 2 天 close 差 0.03 元。沪市 600519.SH 的 close 有 544 天分歧（见 §5 归因），open/high/low 全历史 0 分歧；300104.SZ 仅 1 天。
- **成交额**：差异全部为 Tushare 精度舍入——Tushare amount 为千元四位小数（精度 0.1 元），银河原始整数精确到 1e-5 元；最大绝对差 0.5–7 元（相对量级 ≤1e-8）。银河精度更高，业务上无关紧要。

### 4.2 指数

- **价格**：沪系指数（000001/000300/000905）2013–2022 年持续存在分歧，close 分歧 1,287–1,402 天；2023 年起收敛到 ≤0.001 点（小数点后 4 位精度级）。深系指数（399001/399006）分歧限于 2013–2016，绝大多数为第 4 位小数精度差异（银河 4 位小数 vs Tushare 3 位），2017 年起精确一致。
- **成交量单位两侧各所口径不一致**：沪系指数银河 volume 数值等于 Tushare vol（手），深系指数银河 volume ≈ Tushare vol×100（股）。接入时单位需按交易所分别固定，不能跨所复用换算。
- **成交额**：除 000001.SH 在 2015-04-20（沪市成交额破万亿、交易所系统爆表日）银河 9,995.5 亿 vs Tushare 11,476.0 亿的极端分歧外，早期沪系指数成交额存在约 0.1% 量级的零星差异；近期一致。2015-04-20 当日各数据源金额均不可靠（交易所公告口径），不宜作为判错依据。

## 5. 分歧归因与第三方仲裁

### 5.1 沪市股票收盘价：口径差异，非随机错误

600519.SH 的 544 天 close 分歧按年分布为 2013:56、2014:110、2017:228、2018:150，**最晚分歧日为 2018-08-17**——恰为上交所收盘价规则从"最后一分钟成交量加权平均价"改为收盘集合竞价（2018-08-20 生效）之前的最后一个交易日。2018-08-20 后 0 分歧。

本地分钟文件（第三方逐分钟源）仲裁：16 个抽样分歧日中银河 close 等于当日最后一笔成交价的有 12 天（其余 4 天等于 Tushare 值）。银河 close = 最后成交价口径。

官方收盘价仲裁（搜狐历史行情，官方值独立转载）：

| 样本 | 官方/搜狐 | Tushare | 银河 |
|---|---:|---:|---:|
| 600519.SH 2013-01-04 close | 206.94 | 206.94 ✓ | 206.96 |
| 600519.SH 2017-12-29 close | 697.49 | 697.49 ✓ | 696.51 |
| 000300.SH 2013-01-04 close | 2524.41 | 2524.409 ✓ | 2524.6871 |
| 000001.SH 2013-01-04 close | 2276.99 | 2276.992 ✓ | 2277.1708 |

末分钟 VWAP 复核（分钟文件 amount/vol）：2013-01-04 为 206.9425≈206.94；2017-12-29 为 697.4690（分钟文件 float32 精度限制，方向上支持官方收盘价≠最后成交价）。

**结论：Tushare 日线 close = 交易所官方收盘价；银河早期沪市日线 close = 最后一笔成交价。** 两者均为可定义口径，但涨跌幅、pre_close、复权和回测惯例都以官方收盘价为基准，且深市（早已是收盘集合竞价）两边本就一致——此差异是银河历史数据的口径负债。银河 2018-08-20 后与官方收盘价精确一致。

补充说明：Tushare 的 pre_close 与其自身 close 链逐日自洽（541/541 分歧日），但该检查对指数是循环论证（指数 pre_close 恒等于前收），不构成独立仲裁；独立仲裁来自搜狐转载与规则边界。

### 5.2 沪系指数早期点位

银河沪系指数早期点位与官方发布值存在可见偏差：000300.SH 2015 年最大 14.0 点（约 0.3%）、2013–2014 年 0.28–4.16 点、2017–2018 年 0.05–2.4 点，2019–2022 年降至 0.1–2.0 点且逐年稀疏，2023 年起仅剩 ≤0.001 点的精度级差异。搜狐抽样仲裁支持 Tushare 为官方发布值（见上表）。推测银河早期指数值为自行计算或经修订的序列，未向供应商求证，标记为未确认归因。

### 5.3 停牌与空响应

语义用例实测：300104.SZ 2017-04-17（全天停牌）银河 `kDataEmpty(-76)`、Tushare 0 行；000001.SZ 2012-12-31 / 2000-01-04（银河覆盖前）银河 `kDataEmpty`、Tushare 正常返回。银河 `kDataEmpty` 的多义性（覆盖前/无效代码/停牌混同）维持既有报告结论，单日 Unit 语义必须结合日历与 Universe 解释。

## 7. 接入建议与待确认

1. `stock_daily` 走 Tushare `daily`（配套 `adj_factor`）；指数日线走 Tushare `index_daily` + 申万 `sw_daily`。沿用[日频与指数接口探查报告](tushare-official-daily-index-2026-10-14.md)与 [ST/指数探查报告](tushare-official-st-index-2026-10-20.md)的契约建议稿。
2. 银河定位为分钟线与集合竞价快照源，不复用于日线主链路。
3. 可选：银河日线作为 Tushare 日线 2013 年后的抽样交叉验收源。若启用，规则必须显式处理两个已知口径差异：2018-08-20 前沪市收盘价（官方 vs 最后成交价）不应用于 ERROR 级判错；指数成交量单位按交易所分别换算。
4. 待确认（不影响日线选型结论）：北交所 920 切换前历史在银河旧代码下的可取性；银河早期沪系指数偏差的供应商归因；若未来需要"最后成交价口径"做研究，银河日线可作派生来源。

## 8. 局限

- 样本为 7 股 + 6 指数；第三方仲裁（搜狐）为 4 个样本日，分钟文件仲裁为 16 个抽样日，均非全历史逐日仲裁。
- 分歧归因中"银河指数早期值为自行计算"为推测；收盘价规则边界是强结构性证据但未逐日验证全部样本股。
- 本地分钟文件为第三方来源（见[原始文件勘察](historical-parquet-survey-2026-09-29.md)），其 VWAP 受 float32 精度限制，只作方向性证据。
- 未测：银河旧代码北交所历史、更多申万/中信等指数族、盘中更新时点、供应商历史修订行为。

## 10. 复现

```bash
# 全量对照（约 2 分钟；银河约 60 次请求，Tushare 55 次请求）
uv run --frozen python scripts/compare_daily_galaxy_tushare.py

# 分歧归因与第三方仲裁（读证据目录 + 本地分钟文件 + 搜狐 API）
uv run --frozen python scripts/analyze_daily_compare.py \
  --evidence data/probes/<daily-compare-目录>
```

需要 `.env` 中 `TUSHARE_TOKEN` 与 `AD_USERNAME/AD_PASSWORD/AD_HOST/AD_PORT`；银河侧要求直连路由（进程内清除代理环境变量，TUN 接管时仍会失败）。两次全量执行（daily-compare-20261022-003646 预演、daily-compare-20261022-010855 正式）行数与对照结果完全一致。
