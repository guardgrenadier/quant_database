# 网盘分钟历史文件勘察（2026-09-29）

## 文件与覆盖

实际来源是 `data/raw/stock_1min/year=YYYY/YYYYMMDD.parquet`，**按年目录、按交易日文件**，不是单个年度文件。共 3,954 个文件、约 53 GiB、Parquet 元数据合计 3,380,472,530 行；起止日期为 2010-01-04 至 2026-04-17。2010–2025 年各有 238–245 个日文件，2026 年截至 04-17 有 68 个。元数据中没有零行文件，目录年份与文件名年份一致。原文件永久保留，导入只读。

## Schema 与映射

全部文件的业务列一致：`code`、`trade_time`、`close/open/high/low`、`vol`、`amount`、`date`、`pre_close/change/pct_chg`。其中 3,949 个文件另含 pandas 索引列 `__index_level_0__`，5 个不含；导入忽略索引和特征列。

| 源列 | temp / canonical 口径 |
| --- | --- |
| `code` 字符串 | `ts_code`，保留交易所后缀 |
| `trade_time` 字符串 | 上海本地无时区 bar 标签；只取目标日 `09:30:00–15:00:00` |
| `date` 字符串 `YYYYMMDD` | 入场时核对文件名和 `trade_time` 日期，不物化该列 |
| OHLC `float32` | 源数值文本进 temp，dbt 转为 `DOUBLE` |
| `vol` `float32` | 抽样均为整数股；进 temp 后由 dbt 转为 `BIGINT` |
| `amount` `float32` | 样本约等于价格 × 股数，按**元**解释；沿用 dbt `×100`、half-up 舍入为整数分 |
| 无 `freq`、`extracted_at` | temp 固定 `freq='1MIN'`；历史 `extracted_at=NULL` |

抽查 2010-01-04、2018-07-04、2024-04-17、2026-04-17：日文件行数分别为 407,772、850,248、1,299,923、1,326,946；代码/日期不匹配、`vol` 小数、负 `amount`、重复 `(code, trade_time)` 均为 0。2024-04-17 有 7,440 行晚于 15:00，最晚 15:30；因此入场必须逐行裁到紧窗。抽样不能代表全部 3,954 日。

## 入场信任级别

文件 schema、时间口径和目录覆盖已勘察。**API 重叠期逐行抽样对比与 D6 谓词覆盖率对照尚未完成**：当前工作区没有已发布的 V2 `stock_basic` 快照，也没有把 2026-04-17 的同代码 API 结果与网盘文件配对。历史导入脚本应先输出这两项检查的报告；缺失时只允许 dry-run，不执行批量发布。差异和覆盖缺口按 V2 作为 warn 留痕，信任级别在抽样报告中明确标注。
