# 网盘分钟历史文件勘察（2026-09-29）

## 文件与覆盖

实际来源是 `data/raw/stock_1min/year=YYYY/YYYYMMDD.parquet`，**按年目录、按交易日文件**，不是单个年度文件。共 3,954 个文件、约 53 GiB、Parquet 元数据合计 3,380,472,530 行；起止日期为 2010-01-04 至 2026-04-17。2010–2025 年各有 238–245 个日文件，2026 年截至 04-17 有 68 个。元数据中没有零行文件，目录年份与文件名年份一致。原文件永久保留，导入只读。

## 源文件 Schema 与抽样观察

全部文件的业务列一致：`code`、`trade_time`、`close/open/high/low`、`vol`、`amount`、`date`、`pre_close/change/pct_chg`。其中 3,949 个文件另含 pandas 索引列 `__index_level_0__`，5 个不含。

| 源列 | 原始文件观察 |
| --- | --- |
| `code` | 字符串，含交易所后缀 |
| `trade_time` | 字符串，上海本地时间标签 |
| `date` | 字符串 `YYYYMMDD` |
| OHLC | `float32` |
| `vol` | `float32`；抽样均为整数股 |
| `amount` | `float32`；样本约等于价格 × 股数，按元解释 |
| `freq`、`extracted_at` | 源文件没有这两列 |

抽查 2010-01-04、2018-07-04、2024-04-17、2026-04-17：日文件行数分别为 407,772、850,248、1,299,923、1,326,946；代码/日期不匹配、`vol` 小数、负 `amount`、重复 `(code, trade_time)` 均为 0。2024-04-17 有 7,440 行晚于 15:00，最晚 15:30。抽样不能代表全部 3,954 日；新项目需自行决定时间过滤及数值转换口径。

## 尚未验证

截至 2026-09-29 的勘察，API 重叠期逐行抽样对比与证券集合覆盖率对照尚未完成，不能据此认定供应商之间逐行一致或全历史覆盖完整。原始解压统计见 `data/raw/stock_1min/extraction_manifest.json`（本地、不入 Git）。旧导入实现、状态账和信任规则已移出当前项目。
